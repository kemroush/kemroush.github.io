Ukládání na GitHub

Změny ve sbírce se ukládají do repa kemroush.github.io (soubor sbirka/collection.json). K tomu stránka potřebuje tvůj GitHub token.

  1. Otevři nový fine-grained token.
  2. Repository access → Only select repositories → kemroush.github.io.
  3. Permissions → Contents: Read and write. Volitelně Actions: Read and write, ať funguje tlačítko „Obnovit ceny“.
  4. Token vlož sem. Zůstane jen v tomhle prohlížeči.
